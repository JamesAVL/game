# The Mighty Boosh — Journey Through the Zooniverse

A pixel-art adventure RPG with rhythm **"crimp-off"** boss battles, themed on
*The Mighty Boosh*. Guide **Vince Noir** and **Howard Moon** out from the
Zooniverse across six surreal worlds, out-crimping a cast of legends to recover
the six scattered **Crimp Records**.

> *"Come with us now on a journey through time and space..."*

All art and audio are **original and generated by code** — pixel-art PNGs are
painted by Python scripts (no Pillow, no network), and the chiptune soundtrack +
sound effects are synthesised live in the browser with the Web Audio API.

## Play

```bash
npm start            # serves at http://localhost:8000 (zero dependencies)
# then open http://localhost:8000 in a browser
```

Any static file server works too, e.g. `python3 -m http.server`.

### Controls
- **Move:** Arrow keys / WASD
- **Talk / confirm:** Z, Enter or Space
- **Back / menu:** X or Esc · **Pause menu:** P · **Mute:** M
- **Crimp battles:** hit the four lanes with **D F J K** (or the arrow keys) in
  time with the falling notes. Land notes to fill your crimp meter and drain the
  boss's; mistimed mashing is punished.

## The journey
The Zooniverse hub has a glowing portal to each world. Portals open as you win
records. Some bosses want a gift first (find Old Gregg a **Bailey's**, bring the
**Crack Fox** something shiny). Beat all six and the Zooniverse gets its funk back.

| World | Guardian |
|-------|----------|
| The Frozen Tundra | The Spirit of Jazz |
| Old Gregg's Sea | Old Gregg |
| The Forest of Bins | The Crack Fox |
| The Nightosphere | Nanageddon |
| The Moon | The Moon |
| Xooberon Temple | Tony Harrison |

## Regenerating assets
Every PNG is reproducible:

```bash
python3 tools/gen_all.py     # or: npm run assets
```
